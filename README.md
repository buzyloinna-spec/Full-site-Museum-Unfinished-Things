# Museum of Unfinished Things — English version

Open `index.html` in a browser. Fonts (Gloock, Instrument Sans, Fragment Mono) load from Google Fonts — internet needed.

- `css/style.css` — all styles; colours and fonts are variables at the top (:root)
- `js/room-01-austen.js` — Exhibit 01, Jane Austen (manuscript pages, typed lines)
- `js/room-02-pieta.js` — Exhibit 02, Michelangelo
- `js/room-03-haring.js` — Exhibit 03, Keith Haring
- `js/intro-and-reflection.js` — opening + “Have you left anything unfinished?”
- `images/` — all photos
